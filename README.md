# 📊 Social Media Sentiment Analysis

A Machine Learning project for analyzing social media sentiment using Natural Language Processing (NLP).

## 🚀 Features

* Text preprocessing
* Sentiment classification
* Machine Learning model
* Model evaluation
* Confusion Matrix
* Classification Report
* Accuracy, Precision, Recall, and F1-Score

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Jupyter Notebook

## 📂 Project Structure

```text

├── dataset/

├── models/

├── README.md

```
